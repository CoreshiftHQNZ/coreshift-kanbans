LDM Finance Website

Vehicle finance built for how New Zealand businesses actually operate.

Standalone finance-first site for LDM Motor Group at finance.ldmmotor.group — one application assessed across a multi-lender panel (UDC preferred, Heartland/Marac, Avanti). Astro static build on Cloudflare Pages with live Motorcentral stock; the calculator and three-step application are the conversion surfaces.

Current phase Phase 1 · Code
Next milestone Lead relay live (forms → email) Q3 2026

The Three Goals

📋
Qualified applications
Finance applications from tradies, SMEs and fleet managers nationwide — the #1 KPI surface is /apply.
🔍
Search + AI visibility
SEO/GEO/AEO ≥ 8/10 at the post-launch audit, Lighthouse mobile ≥ 85, LLM citation rate 15%+ by month 6.
🚚
Live stock, two CTAs
Every Motorcentral vehicle page shows an indicative weekly figure and exactly two next steps: calculate or apply.
