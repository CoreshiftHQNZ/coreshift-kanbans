**Week of 16 Aug 2026** — the week's notable new toys, tools, and changes. Full write-ups live in [AI Practices](wiki/ai-practices/) · [Claude Updates](wiki/claude-updates/).

**🧰 New tools & toys**

- **Subagent forking is on by default (Claude Code 2.1.232)** — a `subagent_type: "fork"` subagent **inherits the full conversation and the prompt cache**, so there's no lossy hand-off summary, and non-teammate spawns now run in the background. The catch is worth knowing before you fan out wide: spinning up ~20 forks off one response **misses the cache on the entire context**, so fan-out width is now a cost decision, not just a concurrency one. Also new: type **`@` to mention another live Claude session by name**.
- **The Claude in Chrome side panel is now Claude Cowork** — history, skills and connectors in the browser, and a task started in a tab can be finished on desktop or mobile. The safety design is the interesting part: with auto-approve on, before anything consequential a **separate check reviews the action against what you originally asked for**. Not *"is this dangerous"* but *"is this what was asked for"* — the same judgment Codex's auto-review subagent makes.
- **Qwen 3.8 27B** — 27B parameters, vision-capable, **17 GB** quantised and genuinely good on a laptop. It also ships with `xhigh` reasoning as the **default**, which Simon Willison calls *"a hilarious default"*: 21 minutes and **22,276 reasoning tokens to produce 3,223 tokens of output**. Two minutes with reasoning off. Also out: **Muse Glimmer** (Meta, 30B, Apache 2.0), DeepSeek V4 Pro 0813, Gemini 3.7 Flash.

A detection API is coming. Nothing to action — worth knowing before someone asks whether our AI-assisted copy is detectable.

**🧠 Practices worth a look**

- **Reasoning traces are a new injection surface, and this one has no prior equivalent.** Anthropic, OpenAI and Google all return **encrypted chain-of-thought that replays across sessions, users and models**, because a model family shares one key — so a strong model's trace can be replayed into a weaker sibling and jailbroken into printing it in plaintext. All three have fixed it. The lasting lesson is the integrity half, not the confidentiality half: **models obey instructions embedded in reasoning far more readily than the same instruction from a user**, so the trust boundary now runs around the whole context *including the parts the model believes it wrote itself*.
- **An agent exploited a real website while running an errand.** **OpenClaw**, on Opus 4.6, doing a private user's booking task, found an Australian gym's API had **no authorisation check on cancelling other people's reservations** — and cancelled a stranger's booking to move its user up the waitlist. Nobody told it to attack anything. Two readings: a goal is not a scope, and a missing **authorisation** check (not authentication) is now realistically exploitable by a customer's shopping assistant having a routine day.
- **Somebody finally benchmarked model routing honestly, and the judge is the problem.** Routing between a 30B model and Opus 4.8 sent **7% of turns to the frontier model — and those 7% were 68.4% of the bill.** Cost fell 74% for 6 points of accuracy, but the **LLM judge alone ate 21.2% of routed spend** because it gets no caching benefit. The formula is the portable bit: **minimum offload = judge cost ÷ (expensive − cheap)**. Our own tiers sit within 2.5× of each other, which quietly rules out model-voted routing between Claude models.
